# Dashboard-Comercial-y-Financiero-Power-BI
Dashboard Comercial y Financiero — Power BI

Descripción

Proyecto de análisis comercial y financiero orientado al seguimiento de facturación, cobranzas y saldos pendientes.

Herramientas
- Power BI
- Power Query
- DAX
- Modelo relacional

Desarrollo
- Limpieza y transformación de datos.
- Modelado de clientes, facturas y cobranzas.
- Creación de medidas DAX.
- Desarrollo de indicadores y visualizaciones.

Indicadores
- Facturación total.
- Cobros aplicados.
- Saldo pendiente.
- Porcentaje de cobranza.
- Análisis por cliente.
